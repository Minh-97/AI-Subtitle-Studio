# Task 018 - Thiết lập quy ước đặt tên cho file và dữ liệu

## Mục tiêu
Đảm bảo file, thư mục, phiên bản và kết quả xử lý đều có tên gọi nhất quán, dễ nhận diện và dễ tra cứu.

## Mô tả
Task này tập trung vào việc xây dựng quy ước đặt tên cho file đầu vào, file tạm, transcript, subtitle, log, output và phiên bản công việc. Mục tiêu là giảm nhầm lẫn và hỗ trợ quản lý dữ liệu hiệu quả.

## Input
- PLAN.md
- docs/architecture.md
- docs/project_spec.md

## Output
- Bộ quy ước đặt tên đầy đủ
- Ví dụ cho từng loại file và thư mục
- Danh sách tên không nên dùng hoặc nên tránh

## API
- Không áp dụng API trong task này.
- Tập trung vào tiêu chuẩn đặt tên và quản lý dữ liệu.

## Test
- Kiểm tra tên file đầu vào, file tạm và file đầu ra không gây nhầm lẫn.
- Kiểm tra quy ước có thể hiểu ngay mà không cần đọc thêm tài liệu.
- Kiểm tra việc dùng cùng tên cho dữ liệu khác không gây xung đột.

## Điều kiện hoàn thành
- Mỗi loại file có quy ước đặt tên rõ ràng.
- Tên file không gây hiểu nhầm giữa các phiên bản dữ liệu khác nhau.
- Quy ước phù hợp với quy trình xử lý và lưu trữ.

## Checklist
- [ ] Đã xác định các loại file cần đặt tên.
- [ ] Đã xây dựng quy ước tên cho từng loại.
- [ ] Đã đưa ví dụ vào tài liệu.
- [ ] Đã xác định tên không nên dùng.
- [ ] Đã áp dụng quy ước vào quy trình nội bộ.
